Claude Code on your own computer, from any browser — no account, nothing stored in the cloud.

First time?

Paste this into your current Claude Code session and let it install RemoteCC for you:

Install RemoteCC on this computer by following https://remotecc.dev/install.md, then tell me how to pair.

Or run it yourself in Terminal:

curl -fsSL https://remotecc.dev/install.sh | bash

Once installed, RemoteCC runs in the background on that computer — nothing in the menu bar or the Dock. You manage it from a terminal: remotecc pair, remotecc status, remotecc devices, remotecc settings.

Installing on this computer? This page pairs by itself as soon as it's done.

After installing: a browser on that computer pairs by itself (reload this page); for a phone or another computer, run remotecc pair and scan the QR code.

Open source (Apache-2.0) — read the installer and all the code before you run it: github.com/Remotecc-dev/remotecc

On Windows?

RemoteCC runs in WSL2 (Ubuntu). In PowerShell: wsl --install -d Ubuntu, open Ubuntu, install Claude Code there, then paste the command above into Ubuntu.

When it's done, your Windows browser opens this page already paired. Details: Windows install guide (for Claude to read: /windows.md).

Automatic updates

Automatic updates: the bridge checks remotecc.dev about once an hour and installs new versions signed by RemoteCC when no task is running. Turn off with remotecc settings auto-update off.

Scan QR code

  1. On the computer running RemoteCC, open a terminal and run remotecc pair (Mac, Linux or Windows WSL). A QR code appears.
  2. Open the iPhone Camera app, point it at the code and tap the remotecc.dev link that appears. Or tap “Scan QR code” here, or take a screenshot of the code and tap “Upload QR image”.
  3. Tap “Connect” on the phone and you're done — no code to type on the computer.

Qua Tailscale

This device and the computer running RemoteCC are signed in to the same Tailscale account. Type that computer's name (or pick it from the list) and tap “Pair”. Then type the 4-digit code shown here into the RemoteCC dialog on that computer.

The computer's name is in the Tailscale app (or `tailscale status`), like your-computer.tailxxxx.ts.net. Once one is paired, your other computers on the tailnet running RemoteCC show up here by themselves.

With a pairing link

  1. Get a pairing link on the computer running RemoteCC: run remotecc pair in a terminal (the link is printed under the QR code).
  2. Send the link to this device (AirDrop, Messages…), paste it below and tap “Pair”.
  3. Type the 4-digit code shown here into the RemoteCC dialog on that computer.

Links expire after a few minutes.

FAQ

How do I use Claude Code from my phone?

Install RemoteCC on the computer that runs Claude Code (curl -fsSL https://remotecc.dev/install.sh | bash), run remotecc pair in a terminal on that computer to show a QR code and scan it with your phone. Then open remotecc.dev on the phone: your Claude Code sessions are there, live.

Does my code or chat go through a server?

No. Your device and your computer talk end-to-end encrypted (X25519 + AES-256-GCM). The relay that connects them only forwards ciphertext and stores nothing; on the same Wi-Fi or Tailscale they connect directly.

Is RemoteCC free?

Yes. The bridge, the web app and the relay are free and open source under Apache-2.0. You use your own Claude plan or API key with Claude Code.

Do I need an account?

No. Pairing a browser with your computer is all it takes; nothing is stored in the cloud.

Which computers does it run on?

macOS, Linux, and Windows through WSL2. Claude Code must be installed and signed in on that computer.

Can I see my Claude usage and my computer's load?

Yes. RemoteCC shows plan limits left in the 5-hour and weekly windows with reset times, tokens and cost per session, and the computer's RAM, CPU temperature and free disk.
