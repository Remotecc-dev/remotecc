RemoteCC — Support

RemoteCC lets you use Claude Code on your own computer from any browser at remotecc.dev, or from the iPhone app RemoteCC. For help or questions, email support@remotecc.dev.

Getting started

On the computer that runs Claude Code, open a terminal and run curl -fsSL https://remotecc.dev/install.sh | bash, then open remotecc.dev and pair. Windows needs WSL2: see the Windows guide.

Stop using RemoteCC

In the web app choose “Forget this Mac”, and revoke devices on the bridge's local page (http://127.0.0.1:7790). To uninstall, run bash ~/.remotecc/app/install.sh uninstall; delete ~/.remotecc to remove all data.

iPhone app

The iPhone app has its own subscription terms and is managed in iPhone Settings → your name → Subscriptions. Refunds are handled by Apple at reportaproblem.apple.com.
